# David Jansson - Portfolio [LAB 2]

A personal portfolio website about me, my interests and my goals as a software developer.

**Lab 2 target grade: [3]**

## Features

- About me, interests, pictures and goals sections
- Contact form
- Feedback form with validation and a live character counter

## Getting started

1. Clone the repository:

```
   git clone https://github.com/DavidJanssonDev/Kristianstad-Lab-2
```

2. Open `src/html/index.html` in your browser.

No installation or server is needed.

## Built with

- HTML, CSS
- Bootstrap (CSS only)
- Vanilla JavaScript
